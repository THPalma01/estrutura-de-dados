# 🧠 Estrutura de Dados em Java

## 🧠 Descrição

Projeto contendo diversas implementações de estruturas de dados e algoritmos em Java, com foco no aprendizado prático.

## 🎯 Objetivo

Compreender e aplicar conceitos fundamentais de estruturas de dados.

## 📚 Conteúdo

* Agenda (estrutura de armazenamento)
* Estrutura estática
* Grafos
* Lista duplamente encadeada
* Árvores
* Métodos de ordenação
* Listas
* Aplicações práticas (laboratório)

## 🛠️ Tecnologias

* Java

## 🧠 Conceitos aplicados

* Estruturas lineares e não-lineares
* Manipulação de memória
* Algoritmos de ordenação
* Organização de dados

## ▶️ Como executar

Abrir o projeto em uma IDE Java e executar as classes individualmente.

## 📌 Observações

Repositório com múltiplos exemplos independentes para estudo.
